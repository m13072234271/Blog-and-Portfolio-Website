## 概述

开发了一组命令行工具，旨在解决日常前端开发中的重复性工作，提升团队开发效率。

## 技术栈

- **Node.js** — CLI 运行环境
- **TypeScript** — 类型安全与更好的开发体验
- **Commander.js** — 命令行参数解析
- **Inquirer** — 交互式命令行提示
- **EJS** — 代码模板引擎

## 核心功能

### 项目脚手架

一键生成标准化的项目模板：

- React + TypeScript 项目模板
- Next.js 全栈项目模板
- 组件库模板

### 代码生成器

根据配置或交互式问答自动生成代码：

- 根据接口定义生成 API 请求函数
- 根据数据库 Schema 生成 Model 层代码
- 自动生成表单验证逻辑

### 自动化构建

集成常用的构建和部署工作流：

- 多环境配置管理
- 构建产物分析与优化
- 一键部署到多个平台

## 项目产出

工具集已在团队内部推广使用，将新项目的初始化时间从 30 分钟降低到 2 分钟以内。
