## 文件系统路由

Next.js App Router 的一大特色是基于文件系统的路由。`app` 目录下的每个文件夹和文件都自动映射为路由：

```
app/
├── page.tsx          → /
├── about/page.tsx    → /about
├── blog/
│   ├── page.tsx      → /blog
│   └── [slug]/
│       └── page.tsx  → /blog/:slug
└── (marketing)/
    └── pricing/
        └── page.tsx  → /pricing
```

### 路由组 `(folder)`

括号命名的文件夹不会影响 URL 路径，仅用于组织代码。非常适合将不同功能区域分组，共享不同的 Layout。

## 布局系统

Layout 是 App Router 最强大的特性之一。它支持嵌套且保持状态：

```
export default function BlogLayout({ children }: { children: React.ReactNode }) {
  return (
    <div>
      <nav>博客导航</nav>
      {children}
    </div>
  );
}
```

### Root Layout

`app/layout.tsx` 是所有页面的根布局，必须包含 `<html>` 和 `<body>` 标签，且至少包含一个全局样式导入。

## 数据获取

### Server Components（默认）

在 App Router 中，所有组件默认都是 Server Components，可以直接使用 `async/await` 获取数据：

```
async function Page() {
  const posts = await fetch('https://api.example.com/posts');
  const data = await posts.json();
  return (
    <ul>
      {data.map(post => <li key={post.id}>{post.title}</li>)}
    </ul>
  );
}
```

### 静态生成与增量再生成

Next.js 提供了多种渲染策略：

- **SSG**: `generateStaticParams` + 无 `cache` 配置
- **ISR**: `next: { revalidate: 3600 }` 
- **SSR**: `cache: 'no-store'` 或 `dynamic = 'force-dynamic'`

## 总结

Next.js App Router 通过 React Server Components 重新定义了全栈开发范式，让开发者能够以更直观的方式构建高性能 Web 应用。
